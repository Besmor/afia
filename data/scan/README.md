# Digital-Maturity Scan

Anonymised results of the 15-pharmacy digital-maturity scan conducted in Conakry, June-July 2026.

## Ethics

All data anonymised. No pharmacy identifiers, staff names, or patient information. Categorical maturity indicators only (has-website: y/n, has-online-inventory: y/n, has-API: y/n, has-e-commerce: y/n, etc.).

## Use

Source of grounding for synthetic ecosystem distributions. See `../synthetic/README.md`.
