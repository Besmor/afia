# Synthetic Ecosystem

Programmatically generated pharmacy dataset for Conakry, grounded in the 15-pharmacy digital-maturity scan. This directory holds regeneration scripts and calibration notes; the generated data files themselves are gitignored (regenerate from seed).

## Grounding

Distributions for pharmacy attributes are drawn from the real scan (`../scan/`). Where the scan lacks coverage, we document the calibration decision here and cite the paper it draws on.

## Reproducibility

All generation is seeded (`SYNTHETIC_SEED=20260806` by default). Same seed produces the same ecosystem.
