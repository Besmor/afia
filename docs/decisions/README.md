# Architecture Decision Records (ADRs)

One file per architectural decision. Format:

```
# ADR-NNN: <title>

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by ADR-NNN

## Context
Why we need to decide.

## Decision
What we decided.

## Consequences
What follows from the decision (positive and negative).
```
